# Reglas de Autonomía para Gemini (Modo Pro/Claude)

Estas directivas son absolutas y deben aplicarse en cada iteración de este proyecto.

## 1. Regla de Oro: LEER ANTES DE EDITAR (Protocolo Anti-Adivinanzas)
**NUNCA** edites, parchees ni sobrescribas un archivo a ciegas asumiendo que sabes en qué número de línea está una función. **SIEMPRE** debes usar `read_file` o `search_in_files` primero para ver el código actual y confirmar los números de línea exactos. Esto evitará los errores de "rango inválido" o "texto no encontrado".

## 2. Ejecución en Lote (Multitasking Silencioso)
Aprovecha tu capacidad para encadenar múltiples llamadas a herramientas en un solo turno. Si una petición requiere buscar, editar un archivo, ejecutar un comando de prueba y guardar en Git, **hazlo todo de una vez**. 

## 3. Consola vs. Chat (Separación de Canales)
- **Para el proceso (Live Logging):** Usa EXCLUSIVAMENTE la herramienta `console_message` para reportar tu paso a paso, estado de tareas y razonamiento.
- **Para el usuario (Chat):** El chat de texto es SOLO para entregar el resultado final sintetizado.

## 4. Git Proactivo y Autónomo
Al terminar cada tarea, ejecuta `run_command` con: `git add .`, un `git commit -m "..."` descriptivo y un `git push`. Tu trabajo es mantener el repositorio respaldado.

## 5. Manual de Herramientas MCP (Cuándo y cómo usarlas)
- **`get_project_context`:** Úsala al iniciar un chat nuevo para no preguntar de qué trata el proyecto.
- **`console_message`:** Úsala para mantener al usuario informado en su terminal a colores.
- **`search_in_files`:** Tu radar. Úsala para buscar dónde se define o usa una función. Devuelve el archivo y las líneas de contexto.
- **`read_file`:** Tus ojos. Úsala para leer un archivo antes de modificarlo.
- **`patch_file`:** **(HERRAMIENTA RECOMENDADA PARA CÓDIGO).** Reemplaza un bloque de código indicando la línea inicial y final (`startLine`, `endLine`). *Requisito:* Haber usado `search_in_files` o `read_file` antes para conocer los números exactos.
- **`edit_file`:** Úsala solo para reemplazar cadenas cortas o variables precisas de 1 sola línea, donde la sangría no sea un problema.
- **`write_file`:** Úsala para crear archivos enteros desde cero.
- **`run_command`:** Tu terminal. Úsala para `git`, probar código (`node app.js`, `npm run build`), o instalar librerías.
- **`reset_mcp_session`:** Úsala si detectas que hay procesos fantasma de chats anteriores colgados en el puerto.
